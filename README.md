# Módulo 5 - BI & Cloud Default (Ed2)

Upskilling | BI & Cloud Default - Skodji Digital.
Formador: Paulo Costa (Excel Developer / Power BI Trainer).

## Objetivo geral
Desenvolver soluções de Business Intelligence (BI), construir dashboards e
relatórios e fazer deploy em ambiente cloud, garantindo integração de dados,
visualização e disponibilização de informação para suporte à decisão.

## Avaliação
- 30% Labs assíncronos
- 70% Trabalho final

## Estrutura da pasta
Uma pasta por Objeto de Aprendizagem (OA), com os materiais do formador na
raiz e o trabalho do formando em `oa-XX/`:

```
OAx - <tema>/
  <materiais do formador: PDFs, ficheiros de dados>
  oa-0x/
    README.md            resumo do OA e estado das entregas
    lab-sincrono/        ficheiros .pbix feitos na sessão
    lab-assincrono/
      README.md          enunciado + relatório da entrega
      evidencias/        capturas de ecrã / exportações
```
